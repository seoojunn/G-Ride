# G-Ride
광주 주요 거점의 이동 병목 현상을 해결하기 위해, AI 경로 최적화 매칭으로 청년들의 교통비를 절감하고 신뢰 기반의 하이퍼 로컬 합승 생태계를 구축하는 'G-Ride' 모빌리티 서비스 개발 프로젝트입니다.

## 소개
이 프로젝트는 광주 주요 거점(전남대, 송정역, 유스퀘어 등)의 이동 병목 현상을 해결하기 위해, AI 경로 최적화 매칭으로 청년들의 교통비를 절감하고 신뢰 기반의 하이퍼 로컬 합승 생태계를 구축하는 모빌리티 서비스입니다.

## 주요 기능
- 다변수 파라미터(실시간 교통 혼잡도, 신호 대기 시간 등) 기반 AI 매칭 엔진 및 지능형 경로 최적화
- 우회 계수 최소화를 통한 배차 효율 극대화 및 탑승자 한계 비용 절감
- 평판 지수, 실시간 안심 경로 공유 등 사용자 불안감을 해소하는 'Trust-Tech' 거버넌스 제공
- FastAPI 및 PostgreSQL(PostGIS)을 활용한 실시간 지오펜싱 및 위치 기반 쿼리 지원

## 사용 방법

2. 실행 (환경 변수 설정, 필요 패키지 설치 및 서버 구동)
